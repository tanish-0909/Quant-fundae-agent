# Quant Fundae Agent

This project implements an AI agent specialized in answering quantitative finance questions. It fine-tunes a Google Gemini model on a curated dataset of Q&A pairs sourced from Paul Wilmott's "Frequently Asked Questions in Quantitative Finance."

## Features

- **PDF Data Extraction**: Scrapes Q&A pairs from the source PDF and builds the training dataset (`pdf_reader.py`).
- **Fine-Tuning**: Fine-tunes the Gemini model on the extracted dataset (`fine_tuning.py`).
- **Query Interface**: Prompts the user for a question and returns an answer using the tuned model (`starter.py`).
- **Data Verification**: Validates the dataset for integrity (`verify_dataset.py`).

## File Structure

- `pdf_reader.py`: Extracts questions and answers from `FAQs in quant.pdf` and writes them to `dataset.py`.
- `dataset.py`: Contains the extracted Q&A pairs as Python lists. Generated by `pdf_reader.py`.
- `fine_tuning.py`: Submits a fine-tuning job to Google using the dataset.
- `starter.py`: Main entry point for querying the model. Uses the fine-tuned model if available, otherwise falls back to the base Gemini model with a quant-finance system prompt.
- `verify_dataset.py`: Checks that `dataset.py` has matching question/answer counts and no empty entries.
- `requirements.txt`: Python dependencies.

## Setup and Installation

1. Clone the repository to your local machine.

2. Install dependencies:

    ```bash
    pip install -r requirements.txt
    ```

3. Create a `.env` file in the root directory and add your Google API key:

    ```
    GOOGLE_API_KEY=your_api_key_here
    ```

4. (Optional) If you have already fine-tuned a model, add the tuned model name:

    ```
    TUNED_MODEL_NAME=tunedModels/your-model-name
    ```

## Usage

### Extracting Data from the PDF

To re-extract the dataset from the source PDF:

```bash
python pdf_reader.py
```

This reads `FAQs in quant.pdf`, parses the Q&A pairs, and writes them to `dataset.py`.

### Verifying the Dataset

To check that the dataset is valid:

```bash
python verify_dataset.py
```

### Fine-Tuning the Model

To start a fine-tuning job with the dataset:

```bash
python fine_tuning.py
```

This submits a tuning job to Google's servers. The job takes time to complete. Once finished, copy the tuned model name from Google AI Studio and set it in your `.env` file as `TUNED_MODEL_NAME`.

### Running the Agent

To query the agent:

```bash
python starter.py
```

If `TUNED_MODEL_NAME` is set, the agent uses the fine-tuned model. Otherwise it falls back to the base Gemini model with a quantitative finance system prompt.
